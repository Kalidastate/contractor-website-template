# Contractor Website Template

A lightweight static website starter for contractors, builders, landscapers, and local service businesses.

## What’s Included

- `index.html` — homepage with hero section, services overview, featured projects, about content, and contact call-to-action.
- `about.html` — company/about page.
- `services.html` — services page.
- `projects.html` — projects/gallery page.
- `contact.html` — contact page.
- `assets/css/style.css` — responsive site styles.
- `assets/js/main.js` — mobile menu toggle and small interactive enhancements.
- `assets/images/` — image and placeholder assets used by the template.

## Getting Started

1. Open the repository in your code editor.
2. Replace text, colors, and images with your brand content.
3. Update the navigation links if you rename pages.
4. Add your real portfolio images in `assets/images/`.
5. Test locally by opening `index.html` in a browser.

## Customize

- Edit `assets/css/style.css` to change typography, colors, and layout.
- Update `assets/js/main.js` if you want extra interactions or form handling.
- Add new pages or sections for testimonials, pricing, or team information.

## Deployment

This is a static site and can be hosted on any static host:

- GitHub Pages
- Netlify
- Cloudflare Pages
- Vercel

## Notes

- The contact form is a static template and requires a backend or form service to submit messages.
- Replace placeholder content with your own company details, services, and project photos.
